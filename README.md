# Bisco Misr × France Cultural Presentation

Live site: https://yehiahs.github.io/bisco-misr-france-cultural-presentation/

## Files
- `index.html` redirects to the main presentation
- `Bisco_Misr_France_Cultural_Presentation.html` contains the slide deck
- `assets/images/backgrounds/` contains localized slide backgrounds for reliable GitHub Pages rendering and PPTX export

## Features
- Full-screen HTML presentation
- Mobile-friendly readable view toggle without changing the slide design
- One-click PPTX export that preserves each slide visually as rendered
- GitHub Pages-ready static hosting

## Exporting to PowerPoint
1. Open the live presentation.
2. Click **Export PPTX**.
3. Wait for the slide rendering to finish.
4. Download `Bisco_Misr_France_Cultural_Presentation.pptx`.

## Local preview
Open `index.html` or `Bisco_Misr_France_Cultural_Presentation.html` in a browser, or serve the folder with any static file server.
